# **App Name**: AI Engineer Portfolio

## Core Features:

- Project Showcase: Display AI projects with detailed descriptions, tech stacks, and results.
- Resume Display: Showcase a dynamically updated resume, available for online viewing or PDF download.
- "About Me" Section: Provide background information, skills, and career goals using the LLM to personalize to match a requested tone.
- Contact Information: Enable visitors to connect by including a contact form.
- Figma import: Tool to import the figma designs that are ready

## Style Guidelines:

- Primary color: Deep blue (#34495E), symbolizing expertise and reliability.
- Background color: Light gray (#ECF0F1), providing a clean and modern backdrop.
- Accent color: Soft turquoise (#3498DB) for highlighting key elements and calls to action, contrasting with the primary and background for clarity.
- Headline font: 'Space Grotesk' sans-serif for headlines; Body font: 'Inter' sans-serif for body text; together, a contemporary and professional aesthetic
- Use simple, line-based icons to represent skills and technologies.
- Maintain a clean, grid-based layout with generous spacing for easy content consumption.
- Implement subtle animations (e.g., fade-ins, transitions) for enhanced user engagement.
